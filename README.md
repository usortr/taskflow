# TaskFlow

Трекер задач с контролем загрузки команды.  
Учебный проект, Кейс 24.

## Команда

| Роль | Имя | Зона ответственности |
|------|-----|----------------------|
| P1 — 1С-разработчик | [ИМЯ] | Конфигурация 1С, импорт/экспорт CSV, отчёты |
| P2 — Фуллстек | [ИМЯ] | Figma-прототип, веб-интерфейс, интеграция |
| P3 — Аналитик | [ИМЯ] | ERD, BPMN, документация |
| P4 — Тестировщик | [ИМЯ] | Тест-кейсы, проверка валидаций |
| P5 — Аналитик данных | [ИМЯ] | Генерация тестовых данных, метрики |
