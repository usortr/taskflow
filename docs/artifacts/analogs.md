| Критерий | **Наш продукт (MVP)** | **Jira** | **Trello** | **Linear** |
|---|---|---|---|---|
| **Целевая аудитория** | Учебные команды 5–10 чел. | Enterprise, IT-команды | Малые команды, личный use | Стартапы, IT-команды |
| **Канбан-доска** | ✅ 4 статуса | ✅ Настраиваемая | ✅ 4 статуса по умолчанию | ✅ Настраиваемая |
| **Учёт времени** | ✅ `time_logs` (часы) | ✅ Плагины (Tempo) | ❌ Только через Power-Ups | ✅ Встроенный тайм-трекинг |
| **Аналитика загрузки** | ✅ `over_alloc_flag`, `on_time_rate` | ✅ Через Jira Reports | ❌ Нет встроенной | ✅ Insights (графики) |
| **Экспорт CSV** | ✅ `workload.csv`, `sla_tasks.csv` | ✅ Через плагины | ✅ Только в платной версии | ✅ CSV/JSON |
| **SLA-контроль** | ✅ `closed_at ≤ due_date` | ✅ SLA policies | ❌ Нет | ✅ Cycle time |
| **Платформа** | 1С:Предприятие + веб-UI | Веб + десктоп | Веб + мобильное | Веб |

| **Кривая обучения** | Низкая (простой UI) | Высокая (много функций) | Очень низкая | Низкая |
| **Трассируемость** | ✅ `status_history` | ✅ Audit log | ❌ Ограниченная | ✅ Audit log |

**Вывод:** Наш продукт — **упрощённый аналог Linear + Toggl**, заточенный под учебные задачи с акцентом на аналитику загрузки и SLA. Ключевое отличие — **встроенный расчёт `over_alloc_flag`** и **экспорт в golden-формате** для приёмки.
