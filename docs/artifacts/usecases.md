## 4.7. Use Cases (≥3)

### UC-01: Импорт данных из CSV

**Актор:** Тимлид  
**Предусловие:** Файлы `users.csv`, `tasks.csv`, `time_logs.csv` существуют в `/data/C24/T1/`  
**Основной поток:**
1. Тимлид открывает обработку «Импорт данных» в 1С
2. Выбирает файл `users.csv` → нажимает «Загрузить пользователей»
3. Система валидирует данные (role ∈ {teamlead, worker})
4. Создаёт элементы справочника «Пользователи»
5. Повторяет для `tasks.csv` и `time_logs.csv`
6. Система выводит отчёт: «Загружено X пользователей, Y задач, Z трудозатрат. Ошибок: N»

**Постусловие:** Данные загружены в справочники и регистры  
**Альтернативный поток:** Если валидация не пройдена → строка отклоняется, ошибка логируется  
**Связь с AC:** AC-05 (идемпотентность)

### UC-02: Перевод задачи по статусам

**Актор:** Исполнитель  
**Предусловие:** Задача в статусе `todo`, назначена исполнителю  
**Основной поток:**
1. Исполнитель открывает канбан-доску
2. Видит свою задачу в колонке «Надо сделать» (todo)
3. Начинает работу → меняет статус на `in_progress`
4. Система записывает в `status_history`: old_status=todo, new_status=in_progress
5. Исполнитель работает → записывает часы (UC-03)
6. Завершает работу → меняет статус на `review`
7. Тимлид проверяет → меняет статус на `done`
8. Система вычисляет `closed_at` = MAX(time_logs.date)

**Постусловие:** Задача в статусе `done`, `closed_at` вычислен  
**Альтернативный поток:** Если попытка пропустить статус (todo → done) → ошибка «Недопустимый переход»  
**Связь с AC:** AC-03 (канбан)

### UC-03: Запись трудозатрат

**Актор:** Исполнитель  
**Предусловие:** Задача в статусе `in_progress`, назначена исполнителю  
**Основной поток:**
1. Исполнитель открывает карточку задачи
2. Нажимает «Добавить час»
3. Вводит: дата (YYYY-MM-DD), часы (decimal, ≥0)
4. Система валидирует:
   - `hours ≥ 0`
   - `user_id == tasks.assignee`
   - `task_id` существует
5. Записывает в регистр `Трудозатраты`
6. Обновляет `fact_h` в дашборде

**Постусловие:** Трудозатраты учтены, `fact_h` обновлён  
**Альтернативный поток:** Если `user_id != assignee` → ошибка «Вы не исполнитель этой задачи»  
**Связь с AC:** AC-04 (дашборд)

### UC-04: Формирование отчёта «Загрузка команды»

**Актор:** Тимлид  
**Предусловие:** Данные загружены, трудозатраты учтены  
**Основной поток:**
1. Тимлид открывает отчёт «Загрузка команды»
2. Устанавливает фильтры: период (YYYY-MM), пользователь (опционально)
3. Система рассчитывает:
   - `est_h` = SUM(estimate_h) по задачам пользователя
   - `fact_h` = SUM(hours) из time_logs
   - `over_alloc_flag` = 1, если fact_h > est_h
4. Отображает табличный документ
5. Тимлид нажимает «Выгрузить в CSV»
6. Система экспортирует `workload.csv`

**Постусловие:** Отчёт сформирован, CSV экспортирован  
**Альтернативный поток:** Если данных нет → отчёт пустой, сообщение «Нет данных за период»  
**Связь с AC:** AC-01 (совпадение с golden)

### UC-05: Контроль SLA (доля задач в срок)

**Актор:** Тимлид  
**Предусловие:** Задачи закрыты (status = done)  
**Основной поток:**
1. Тимлид открывает отчёт «SLA задач»
2. Устанавливает фильтр: период (YYYY-MM)
3. Система рассчитывает:
   - `closed_at` = MAX(time_logs.date) по задаче
   - `on_time_flag` = 1, если closed_at ≤ due_date
4. Отображает табличный документ
5. Тимлид нажимает «Выгрузить в CSV»
6. Система экспортирует `sla_tasks.csv`

**Постусловие:** SLA-отчёт сформирован, CSV экспортирован  
**Связь с AC:** AC-02 (совпадение с golden)
