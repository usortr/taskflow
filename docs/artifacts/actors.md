## 4.6. Список акторов

| Актор | Роль | Описание | Примеры действий |
|---|---|---|---|
| **Тимлид** | `teamlead` | Суперпользователь, распределяет задачи, контролирует загрузку | Импорт CSV, назначение задач, просмотр дашборда, экспорт отчётов |
| **Исполнитель** | `worker` | Рядовой участник, выполняет задачи, учитывает время | Просмотр своих задач, смена статуса, запись часов |
| **Куратор/Преподаватель** | Внешний стейкхолдер | Принимает проект по KPI и артефактам | Проверка golden-файлов, оценка по рубрикам |
| **Команда разработки** | Внутренний стейкхолдер | P1–P5, реализуют MVP | Код, модели, документация, демо |
| **Система (1С)** | Технический актор | Бэкенд, хранит данные, считает KPI | Импорт/экспорт, валидации, расчёты |
